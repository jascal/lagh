Registered 2026-07-26. The last week's arc (blind read → dev campaign → gate

## The strategic read (why the current grind has diminishing returns)

Single-equation SA leaderboards are an away game: the constructions (pivot
inversion, injected novel terms, continuous parameters) can always outrun a
fixed exact grammar, and this week measured the hard boundary — at envelope
epsilon, dense-channel certificates admit approximant impostors, so the
certified track is structurally capped there. Meanwhile lagh's actual
differentiators — machine-checked certificates, calibrated abstention,
zero-wrong, ACTIVE acquisition, verified orchestration — are scored by NO
SA benchmark. The roadmap moves the fight to where those score.

## Horizon 1 — the keystone + the paper (days)

**1a. Significance accounting (the keystone).** Build the α = |H|·q^h
machinery (`DIRECTION_SIGNIFICANCE.md`): every certificate carries a stated
false-certification bound computed from its hypothesis-class size and check
count. This converts this week's discovered boundary ("only small classes may
certify under noise") from a restriction into a THEOREM-SHAPED guarantee, and
re-admits dense channels to track A with explicit α. Validation: RNOISE and
the dev sweeps, which now exist as regression harnesses.
- Deliverable: α on every certificate + null-calibration validation of the
  bound + the certified-randomness abstention product.
- SCOPE CORRECTION (2026-07-26, at implementation start): α is an anti-CHANCE
  guarantee relative to a random null; an approximant impostor is a genuinely
  significant fit of the WRONG form, so α does NOT re-admit dense channels
  under noise — that boundary stands (structure uniqueness remains coherence's
  job). The H1a kill criterion is thus partially pre-triggered, honestly.

**1b. Freeze the LLM-SRBench dev campaign and write the instrument report.**
Declare the plateau (recipe plateaus; achievability open): autonomous SA ~12%,
88% of the LLM-composite, zero structural fabrication on Transform. The report
is publishable INDEPENDENT of leaderboard position — nobody else has: the
zero-wrong record across 5 testbeds + 2 benchmarks; the float32-quantization-
as-declared-noise result; the asymptotic-degeneracy and approximant-impostor
taxonomy; the LLM→grammar distillation loop (proposer teaches, checker
verifies, grammar keeps). Target: tech report / workshop preprint.

## Horizon 3 — own the benchmark class (weeks): LawSystemBench + the system discoverer

The week's sharpest strategic observation (user, 2026-07-25): every benchmark
in this space assumes ONE equation per dataset, roles pre-labeled, explicit
form. Real theories are coupled systems with shared constants and implicit
invariants. Nobody benchmarks that; the workspace already owns the substrates
with KNOWN system-level ground truth (econ-sae SFC macroeconomy, sm-sae
Standard Model bundle, bio-sae).

**3a. LawSystemBench**: manufacture the benchmark from those substrates —
coupled equations, shared parameters, conserved quantities, target roles
UNLABELED. Publish it with baselines (the manifesto's instrument thesis,
turned outward).
**3b. The system discoverer**: extend lagh certificates to conjunctions —
per-equation discovery under the Orca machine, cross-equation coherence
(shared rationals must agree), invariant detection, system-level zero-wrong.
- Deliverable: the first certified system-discovery result on a public
  benchmark WE define — competitors must adopt certification to even enter.
- Kill criterion: if system certificates reduce to trivially independent
  per-equation runs (no cross-equation signal), the benchmark still stands
  alone as a contribution.
